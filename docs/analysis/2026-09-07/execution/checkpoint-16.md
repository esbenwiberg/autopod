# Checkpoint 16: interrupted artifact finalization and snapshot integrity

The complete required pipeline passed on clean commit 6789690c5718d4b487417758bde9e079b3fd7532: install, lint, build, configured typecheck, repository tests and deployment/cleanup safeguards, audit (zero known vulnerabilities), and secret scan. Daemon: 4,440 passes and one existing skip. Exact starting identity and full receipt are retained. This predates the following changes, so final committed pipeline verification remains required.

New RED regressions showed the sandbox reaper deleting failed artifact sources and deleting a lifecycle resumed while preservation was pending. Failed artifact sources now remain under artifact finalization ownership. Reaper generation, target, status and pending-decision checks run immediately before deletion and before clearing a confirmed deletion. This prevents the reproduced pre-deletion race; it is not a claim that an already-dispatched remote deletion can be cancelled.

Local and sandbox restart regressions exposed interrupted artifact collection being killed, parked as coding work, or ignored after container removal. Reconciliation now reads the current full pod (ordinary list results lack the completion journal), recognizes entered collection for the current generation, and retains its source/snapshot for finalization recovery. It neither enqueues a worker nor starts, quiesces or suspends a settled artifact sandbox. Unanswered decisions retain their prior guard.

New snapshots receive a sibling versioned integrity receipt before publication. The digest covers collected paths, entry types, modes, regular-file bytes and symlink targets without following symlinks. Inventory is bounded to 100,000 entries and 1 GiB of regular-file bytes; an exceeded bound prevents completion and retains the original source. Recovery verifies expected root, generation, completion cycle and digest. Changed, missing or unreceipted snapshots remain unresolved. Legacy snapshots have no automatically manufactured receipts.

An actual manager regression models the durable state after snapshot publication and container removal but before the final status commit, then creates a fresh manager. A tampered snapshot fails with ARTIFACT_SNAPSHOT_UNVERIFIED. Restoring the original bytes allows duplicate Resume calls to complete using the existing snapshot without another extraction, container deletion or worker. A separate RED duplicate-completion regression originally copied twice; generation/cycle-scoped in-process coordination now coalesces those calls into one collection and cleanup.

Desktop and mobile retain the recovery action even when a snapshot is already recorded, labeled Resume artifact finalization. Final affected suites: daemon 515 passes, mobile 108 passes, desktop 338 passes, seven package builds pass. Mobile browser interaction verifies the snapshot-integrity error remains actionable and a later successful response refreshes completion without WebSocket delivery. Native interaction remains unverified. Receipts remove only trailing whitespace and surplus EOF blank lines; raw logs remain in /private/tmp/autopod-artifact-*.

Remaining: this verifies the bytes successfully copied by the adapter, not an independent inventory of the original container. It does not claim power-loss fsync proof, a filesystem/SQLite atomic commit, recovery of orphan snapshots published before their DB path, or durable cross-process side-effect claims. The restart test constructs a crash state and fresh manager; it does not kill and reboot a live daemon. Legacy/no-receipt restoration, interactive completion duplicates, the interval before entering collection, generation changes after external cleanup dispatch, and optional artifact branch delivery need further reconciliation. The broader W1-W6 items, task-wide provider/rework budgets, outcome reconciliation, final benchmark, native/live acceptance and prepared release gate remain open. No production changes were made; pending read-only guest inspection approval is unchanged.

Fixture hygiene: completion tests now allocate and remove their own temporary DATA_DIR. Existing fixtures now delete absent environment variables instead of assigning the stringified undefined value. Generated synthetic artifacts under the isolated checkout were removed.
