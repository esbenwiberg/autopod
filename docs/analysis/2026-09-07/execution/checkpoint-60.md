# Checkpoint 60: owned runtime-session extraction publication

Three RED cases reproduced late extraction publication after cancellation/supersession and the actual event consumer timeout lacking any publication cancellation signal. The timeout previously ended waiting while the backend could later mirror stale files into shared recovery history.

The container extraction interface now accepts an optional AbortSignal and synchronous ownership assertion. Docker and sandbox implementations check before collection and immediately before mirroring. Guarded collectors use unique private staging directories beside the destination, so an old collector neither writes into current recovery files nor removes another collector's staging. Routing preserves the exact guard. Existing unguarded extraction semantics remain. The shared guard helper has no asynchronous gap before the synchronous filesystem publication.

The actual runtime-session synchronization path passes the consumer's lifecycle, invocation and durable provider-ordinal ownership check, aborts on timeout, and revokes publication on settlement. An old network read may continue in its isolated staging directory; this is publication cancellation, not evidence of remote request/process termination. Each collector cleans its own staging only after it settles.

Sixteen focused cases passed, covering both backend publication fences, overlapping old/new collection, routed guard identity, actual timeout wiring, lifecycle/provider replacement during synchronization, and existing completion/failure behavior. The final five affected suites passed 731 tests with one platform skip. The additional guarded and unguarded round-trip cases restore session files into a subsequent local sandbox fixture. Build and configured DTS passed. The final removal of a redundant consecutive initial assertion is included in the committed-source full pipeline below.

This protects late publication and independent staging. It does not prove atomic whole-directory replacement, power-loss/fsync durability, remote termination, cross-process locking throughout filesystem publication, or cleanup of never-settling/orphaned private collectors.
