# Checkpoint 63: observed reviewer termination and retained known usage

Five RED runner cases demonstrated that host Claude and the agentic host reviewer settled immediately after SIGTERM, while container Claude could wait indefinitely for a hanging kill request. Two actual validation RED cases demonstrated replay or fallback to an earlier review result when termination was unconfirmed. A further RED case caught loss of measured earlier-tier usage in the new fail-closed path; that regression is fixed and retained.

Host Claude now waits for its owned process exit after timeout or output overflow, escalates SIGTERM to SIGKILL after five seconds, and reports a distinct termination-failed outcome if exit remains unobserved after ten seconds. Sending a signal is not exit evidence. Late exit cannot rewrite a settled unconfirmed result. A previously observed exit is used when descendant-held pipes delay collector completion, without signalling an already exited process. Cancelled output is bounded and timers are cleared. A failed signal request is unconfirmed termination, never a successful cancellation.

Container Claude now bounds kill delivery separately from observed exit, like Codex.
