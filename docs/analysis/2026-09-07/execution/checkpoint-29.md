# Checkpoint 29: retain approval identity across status callbacks

Three RED fault-injection cases replaced a lifecycle synchronously from the approved, merging and complete status listeners. transition() publishes and then reads the current row; the approval path could therefore adopt the replacement row as its next operation snapshot. The approved callback produced an invalid transition after reaching approval metadata; merging/complete callbacks resolved instead of rejecting stale work.

The no-new-changes approval path now retains explicit status snapshots tied to the original generation and resource identity. It checks the current row after the approved transition, after readiness approval publication, after merging, after cleanup, after the complete transition and before dependent dispatch. Replacement resources and readiness metadata remain unchanged, and a replacement triggered by the status callback receives no spurious pod.completed event. Checks surrounding awaits from checkpoint 28 remain. Fifteen focused no-changes tests pass, including all three new callback cases; package lint and seven builds pass. The next full pipeline covers this commit together with checkpoint 28's formatter correction.

No new response contract or operator action was added here. The existing HTTP stale-approval error uses the same supported error presentation; checkpoint 28 retains actual API/CLI and mobile failure/retry evidence and native client tests. Native UI interaction and cross-process/live acceptance remain unverified.

W1.1 and W1.3 remain partial. In particular, normal approval paths with PR/rebase/merge/push side effects still need original-generation checks and durable admission/receipts across their own waits and callbacks. Nested event delivery order, generation-aware consumers, immutable source proof during approval and complete crash reconciliation remain open. This checkpoint does not claim all terminal transitions or all delivery paths are durable. No production activity, migration, paid execution or publication occurred.
